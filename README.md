# Hush
One big play/pause button, one looping track. Offline PWA.

**Swap the sound:** replace `noise.ogg` with your own file (keep the name, or edit `src` in `index.html` and `FILES` in `sw.js`), then bump `V` in `sw.js` (e.g. `hush-v2`). Open the app twice to pick up the update.
Tip: use a loop-friendly file (ogg/opus, a few minutes long) to avoid a gap at the loop point.
